# TI-84 Evo module

This package declares one read-only screenshot operation for the observed
`0451:e018` calculator identified as `TI-84 Evo`. It is intentionally not a
general calculator module. `device.lua`, `cbor.lua`, `evo.lua` and `screen.lua`
are the authoritative Lua source set; `artifacts/` is generated by
`tools/check-lua-artifacts.mjs`.

The declaration uses the retained read-only `dynamicinfo` transaction as its
protocol establishment probe. Capturing a screenshot is the only operator
operation and returns an `image/bmp` file.
